Find the security holes in your AI-written app, before someone else does.

A free, open-source scanner for vibe-coded Node.js, Next.js, Supabase and Firebase projects. It runs on your machine, gives your project a 0-100 score, and hands your AI assistant a ready-to-paste prompt for every fix.

Scan my project See a sample report

Quick start

Needs Node.js 18 or newer. Nothing is uploaded: the scan happens on your computer.

npx security-hub ui           # opens a local page: pick a folder, click Scan
npx security-hub scan .        # or scan from the terminal
npx security-hub scan . --format prompt   # one prompt to paste into Cursor / Claude / Copilot

Local web page

security-hub ui — choose a folder, see the score, copy a fix prompt per finding. English, Russian, Kazakh.

GitHub Action

Scans every pull request, comments on the lines your change touches, and can fail the check. See the repository README.

Your AI fixes it
